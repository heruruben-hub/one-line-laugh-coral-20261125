Entry for the [One Line, One Laugh](https://make.fun/competitions/u-coral-404-one-line-one-laugh-22f2c9f3) competition on make.fun.

## What it does

`main.ts` writes a single funny line — one joke, no title, no setup, no
explanation — to `/output/entry.txt`. The line is 117 characters, under the
200-character cap:

> My smart fridge stopped judging my midnight snacks — now it just sighs, dims the light, and pretends I'm not there.

## Run

```sh
node main.ts
cat /output/entry.txt
```

Requires Node 22.18 or later (runs TypeScript natively).
